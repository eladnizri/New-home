# מפת הבית החדש

אפליקציית תכנון קניות לדירה החדשה — מפה אינטראקטיבית של הדירה, רשימת מוצרים לכל חדר,
ומעקב תקציב מלא. הכל בקובץ אחד, בלי שרת ובלי התקנה.

## מה יש בפנים

**מפה** — תוכנית הדירה משורטטת מחדש כ־SVG לפי התוכנית האדריכלית: 14 חדרים לחיצים.
עוצמת הצבע של כל חדר מייצגת כמה מהפריטים בו כבר סגורים. לצד המפה מפתח חדרים עם
צפי ההוצאה של כל אחד.

**חדר** — לחיצה על חדר פותחת מגירה עם רשימת המוצרים שלו. לכל פריט שלושה סטטוסים —
לוקחים מהבית / צריך לקנות / נקנה — מחיר משוער, מחיר בפועל, חנות, וזמן אספקה בשבועות.
לכל חדר תקציב נפרד עם חיווי חריגה.

**כל הפריטים** — טבלה מלאה עם חיפוש, סינון לפי חדר וסטטוס, ומיון. מציגה את הפער בין
ההערכה למחיר שנסגר בפועל.

**ציר זמן** — שישה שלבי הזמנה שנספרים אחורה מתאריך הכניסה, מנגרות וארונות (זמן הייצור
הארוך ביותר) ועד ההשלמות של הרגע האחרון. כל שלב מקבל חלון הזמנה מחושב, ומסומן כפתוח,
עתידי או באיחור. שינוי תאריך הכניסה מזיז את כל החלונות.

**כספים** — תקציב מול צפי לכל חדר עם סמן תקציב, חלוקה לפי סטטוס, ועשרת הפריטים היקרים.

## נתונים ושמירה

הנתונים נשמרים ב־`localStorage` של הדפדפן, ונשמרים אוטומטית אחרי כל שינוי.
אין שרת, ולכן אין סנכרון אוטומטי בין מכשירים. שלוש דרכים להעביר את המצב:

- **גיבוי לקובץ** — שמירת קובץ JSON
- **קוד סנכרון** — העתקת המצב כטקסט לשליחה
- **ייבוא** — הדבקת קוד או תוכן קובץ, מחליף את הרשימה הנוכחית

## הרצה

```
open index.html
```

הקובץ עצמאי לחלוטין: אין תלויות, אין בנייה, אין קריאות רשת. הפריטים והמחירים
שמגיעים כברירת מחדל הם נקודת פתיחה מכוילת לשוק הישראלי, לא המלצה — ערכו אותם חופשי.

## מבנה

הכל ב־`index.html`:

- `ROOMS` — גאומטריית החדרים (מלבנים או path), שטחים ומידות
- `SEED` — קטלוג פריטי ברירת המחדל לכל חדר: `[שם, מחיר משוער, שבועות אספקה, סטטוס]`
- `PHASES` — שלבי ההזמנה בציר הזמן, מוגדרים בשבועות לפני הכניסה
