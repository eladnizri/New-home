# הבית החדש

אפליקציית תכנון קניות לדירה החדשה. מפה אינטראקטיבית, רשימת מוצרים לכל חדר,
ציר זמן הזמנות ומעקב תקציב — הכל בקובץ HTML אחד, בלי שרת ובלי התקנה.

הנתונים נשמרים ב־`localStorage` של המכשיר. **אין סנכרון ואין חשבון.**
מי שמחליף מכשיר או מנקה את הדפדפן — צריך גיבוי (בהגדרות).

## מסכים

**חדרים** (מסך הבית) — ארבעה אריחי סיכום ומתחתם כרטיס לכל חדר: טבעת התקדמות,
פילוח לפי סטטוס, וצפי מול תקציב. מסונן ב־הכל / נותרו / הושלמו. אפשר להוסיף חדר
מכפתור בתחתית הרשימה, ובתוך כל חדר לערוך את שמו או למחוק אותו כליל.

**ציר זמן** — שישה שלבי הזמנה שנספרים אחורה מתאריך הכניסה, מנגרות וארונות ועד
ההשלמות האחרונות. לכל שלב חלון הזמנה מחושב, מסומן כפתוח, עתידי או באיחור.

**כספים** — צפי מול תקציב, הוצאה לפי שלב הזמנה, הוצאה מצטברת לאורך החודשים,
ופירוט לפי חדר עם סמן תקציב.

**חדר** — לחיצה על כרטיס חדר פותחת גיליון תחתון: שם החדר ניתן לעריכה בראש
הגיליון, ולכל פריט שלושה סטטוסים (לוקחים מהבית / צריך לקנות / נקנה), מחיר
משוער, מחיר בפועל, חנות, וזמן אספקה בשבועות שמזין את ציר הזמן. בתחתית הגיליון
אפשר להוסיף פריט או למחוק את החדר כולו.

## עיצוב

שתי שכבות צבע. שכבת הפסטל צובעת משטחים גדולים שתמיד נושאים תווית — אריחים,
כתמים ומילויים. שכבת הנתונים היא גרסה עמוקה של אותם גוונים, ומשמשת בכל מקום
שבו הצבע באמת מקודד מידע: נקודות סטטוס, טבעות וסימוני גרפים.

הפסטלים המקוריים נכשלו בהפרדת עיוורון צבעים — המשמש והירוק נבדלו ב־ΔE 11.4
בלבד גם בראייה תקינה. שכבת הנתונים תוקפה מול שני המצבים:

```
light  #96517A  #C4762B  #12866E
dark   #C56AA6  #C9781F  #0EA083
```

הירוק הוסט לכיוון טורקיז כדי לפתור התנגשות עם הכתום בעיוורון צבעים מסוג פרוטן.

## הרצה

```
open index.html
```

הקובץ עצמאי לחלוטין: בלי תלויות, בלי בנייה, בלי קריאות רשת.
הפריטים והמחירים שמגיעים כברירת מחדל הם נקודת פתיחה מכוילת לשוק הישראלי,
לא המלצה — ערוך אותם חופשי.

## מבנה

הכל ב־`index.html` — מסמך HTML עצמאי אחד עם `meta viewport` להתאמה מלאה לטלפון:

- `DEFAULT_ROOMS` — רשימת החדרים ההתחלתית (מזהה ושם בלבד; נשמרת ב־state
  וניתנת לעריכה, הוספה ומחיקה)
- `SEED` — קטלוג ברירת המחדל לכל חדר: `[שם, מחיר משוער, שבועות אספקה, סטטוס]`
- `PHASES` — שלבי ההזמנה, מוגדרים בשבועות לפני הכניסה
